# Repo rules for AI agents

## Merging pull requests
Standing permission: merge a PR yourself as soon as
1. every CI check on its latest commit is green (skipped is fine, failed or pending is not),
2. every review comment has been addressed: fixed, or answered with a reason, and resolved,
3. it has no merge conflicts.

Don't ask first. If any of these isn't true, fix it or say what's blocking. Never merge with red CI or open review threads.
